# Legacy Portfolio Landing Page

This repository previously held an experimental static portfolio. It is retained only as a
small, transparent landing page that points to the maintained portfolio source:

- [ZQ](https://github.com/mzquadri/ZQ)

The prior presentation included illustrative visualizations and claims that were not backed by
versioned project artifacts. Those materials were removed rather than presented as verified work.

## Local preview

Open `index.html` in a browser. No build step or server is required.
